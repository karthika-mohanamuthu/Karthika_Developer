# Karthika M — Portfolio

A responsive personal portfolio built with HTML, CSS, JavaScript and Three.js.

## Run locally
1. Extract the ZIP file.
2. Open the `Karthika-3D-Portfolio` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. An internet connection is needed for Google Fonts and the Three.js CDN particle effect. The rest of the page works without the 3D library.

## Personalise
- Replace `images/profile.jpg` to change the profile photo.
- Update links and project descriptions in `index.html`.
- Replace `assets/Karthika-M-Resume.pdf` if you want to publish a newer résumé.

## Publish free with GitHub Pages
Create a GitHub repository, upload the contents of this folder (not the ZIP itself), then open Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

## Notes
- No phone number is displayed on the portfolio.
- The résumé included here is a portfolio-friendly copy with the phone number omitted.
- Project cards link to the GitHub repositories; they do not claim the projects are live-hosted.
